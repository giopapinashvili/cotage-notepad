# აგარაკის ჯავშნები — ოჯახის საერთო რვეული

მარტივი ქართული ვებაპი აგარაკის ჯავშნებისა და ჩანაწერებისთვის. საიტი იხსნება კოდისა და პაროლის გარეშე; ოჯახის წევრები ერთსა და იმავე ონლაინ რვეულს იყენებენ. ჩანაწერები Cloudflare Worker-ის SQLite Durable Object-ში ინახება და ცვლილებები დაკავშირებულ მოწყობილობებს მაშინვე ეზიარება.

> **წვდომის შენიშვნა:** შესვლა და პაროლი გამორთულია. საიტის ბმულის მქონე ნებისმიერ ადამიანს შეუძლია ჩანაწერების ნახვა, დამატება, შეცვლა და ჩამოტვირთვა. გაუზიარე ბმული მხოლოდ ოჯახს. თუ მოგვიანებით წვდომის შეზღუდვა დაგჭირდება, ცალკე ავთენტიფიკაციის დაყენებაა საჭირო.

## გაშვება Cloudflare-ზე

დაგჭირდება Node.js 22 ან უფრო ახალი და Cloudflare ანგარიში. VS Code-ში გახსენი პროექტის საქაღალდე და ტერმინალში გაუშვი:

```bash
npm ci
npx wrangler login
npx wrangler deploy
```

`wrangler deploy` განათავსებს გვერდსაც და საერთო მონაცემების სერვერსაც. გახსენი ტერმინალში გამოჩენილი `https://...workers.dev` მისამართი და იგივე ბმული გაუზიარე ოჯახის წევრებს. Dashboard-ის პირდაპირი ფაილების ატვირთვა და VS Code-ის **Go Live** ამ პროექტისთვის საჭირო არ არის.

## ადგილობრივი გაშვება

```bash
npm ci
npm run dev
```

ტერმინალში გამოჩენილი `http://localhost:8787` მისამართი გახსენი. ლოკალური სატესტო ჩანაწერები Cloudflare-ზე გამოქვეყნებულ საიტთან საერთო არ არის.

## ჯავშნის დამატება

1. აირჩიე თავისუფალი თარიღი და დააჭირე **„ჯავშნის დამატებას“**.
2. შეავსე თარიღი, საათები და საჭირო ინფორმაცია.
3. **„შენახვამდე“** ცვლილებები სხვებს მონახაზად უჩანთ; დააჭირე **„შენახვას“**, რომ ჯავშანი საბოლოოდ ჩაიწეროს.

აპი ამოწმებს თარიღის სისწორეს, თანხას და მოქმედ ჯავშნებთან დროის გადაკვეთას. „ისტორია“ აჩვენებს ცვლილებებს; **„ასლის ჩამოტვირთვა“** ინახავს ჯავშნებისა და ისტორიის JSON ასლს.

## საიტის განახლება

კოდის ცვლილებების GitHub-ზე ატვირთვა თავისით Cloudflare საიტს არ აახლებს. ახალი ვერსიის გასაშვებად პროექტის საქაღალდიდან გაუშვი:

```bash
npm run deploy
```

არ შეცვალო `wrangler.jsonc`-ში Worker-ის სახელი ან Durable Object-ის კონფიგურაცია, რათა ძველი ონლაინ ჯავშნები შენარჩუნდეს.

## შემოწმება

```bash
npm run check
npm run test:integration
```

ინტეგრაციული ტესტები დროებით Wrangler სერვერსა და იზოლირებულ საცავს იყენებს.
