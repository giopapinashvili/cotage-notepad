# აგარაკის ჯავშნები — ოჯახის საერთო რვეული

მარტივი ქართული ვებაპი აგარაკის ჯავშნებისა და ჩანაწერებისთვის. პირველად გახსნისას აირჩიე სახელი — გიო, ვეკო, შორენა ან ლიკა. არჩევანი ამ მოწყობილობაზე ინახება; შემდეგ საიტი ავტომატურად იმავე სახელით გაიხსნება. ჩანაწერები Cloudflare Worker-ის SQLite Durable Object-ში ინახება და ცვლილებები დაკავშირებულ მოწყობილობებს მაშინვე ეზიარება.

პირველად შესვლისას შეიყვანე პაროლი `20031003`. სწორი პაროლის შემდეგ ამ ბრაუზერში ხელახლა შეყვანა საჭირო აღარ იქნება; სხვა მოწყობილობაზე ან ბრაუზერის მონაცემების გასუფთავების შემდეგ თავიდან შეიყვანე.

> **წვდომის მნიშვნელოვანი შენიშვნა:** ეს ერთჯერადი ფანჯარა მონაცემების ნამდვილ დაცვას არ უზრუნველყოფს. პაროლი ბრაუზერის კოდში ჩანს და სერვერის API-ებიც ღიაა. ბმულის მქონე ადამიანს შეუძლია კოდის ნახვა ან API-ზე პირდაპირი წვდომა და ჩანაწერების ნახვა, შეცვლა ან ჩამოტვირთვა. ეს მხოლოდ მარტივი ეკრანის ჩამკეტია; რეალური დაცვისთვის სერვერზე ავთენტიფიკაციაა საჭირო.

## გაშვება Cloudflare-ზე

დაგჭირდება Node.js 22 ან უფრო ახალი და Cloudflare ანგარიში. VS Code-ში გახსენი პროექტის საქაღალდე და ტერმინალში გაუშვი:

```bash
npm ci
npx wrangler login
npx wrangler deploy
```

`wrangler deploy` განათავსებს გვერდსაც და საერთო მონაცემების სერვერსაც. გახსენი ტერმინალში გამოჩენილი `https://...workers.dev` მისამართი და იგივე ბმული გაუზიარე ოჯახის წევრებს. Dashboard-ის პირდაპირი ფაილების ატვირთვა და VS Code-ის **Go Live** ამ პროექტისთვის საჭირო არ არის.

## ადგილობრივი გაშვება

```bash
npm ci
npm run dev
```

ტერმინალში გამოჩენილი `http://localhost:8787` მისამართი გახსენი. ლოკალური სატესტო ჩანაწერები Cloudflare-ზე გამოქვეყნებულ საიტთან საერთო არ არის.

## ტელეფონზე დაყენება

HTTPS საიტის გახსნისა და სახელის არჩევის შემდეგ, Android-ის მხარდაჭერილ ბრაუზერში აპის დაყენების შეთავაზება გამოჩნდება; დააჭირე ბრაუზერის ფანჯარაში **Install**-ს. iPhone-ზე საიტი პირველ შეხებაზე აჩვენებს ინსტრუქციას: Safari-ში დააჭირე **Share → Add to Home Screen**. PWA-ის დაყენება საიტს აპივით ხსნის, მაგრამ ჯავშნების სინქრონიზაციისთვის ინტერნეტი მაინც საჭიროა.

## ჯავშნის დამატება

1. აირჩიე თავისუფალი თარიღი და დააჭირე **„ჯავშნის დამატებას“**.
2. შეავსე თარიღი, საათები და საჭირო ინფორმაცია.
3. **„შენახვამდე“** ცვლილებები სხვებს მონახაზად უჩანთ; დააჭირე **„შენახვას“**, რომ ჯავშანი საბოლოოდ ჩაიწეროს.

არჩეული თარიღი ჯავშნის შესვლის დღეა, გასვლა კი ნაგულისხმევად მომდევნო დღესაა. „ივსება“ და შემვსებლის სახელი სხვებს მხოლოდ მაშინ უჩანთ, როცა ვინმე აქტიურად წერს; ჩანაწერის დახურვისას ეს მაჩვენებელი ქრება.

ჯავშანზე ჩანს, ვინ შექმნა ის და ვინ შეიტანა ბოლო ცვლილება. „ისტორია“ აჩვენებს თითოეულ ცვლილებასა და მის ავტორს; **„ასლის ჩამოტვირთვა“** ინახავს ჯავშნებისა და ისტორიის JSON ასლს.

სხვა მოწყობილობაზე სახელის არჩევა თავიდან მოგიწევს. ამავე მოწყობილობაზე ანგარიშის შესაცვლელად დააჭირე **„სახელის შეცვლას“**.

## საიტის განახლება

კოდის ცვლილებების GitHub-ზე ატვირთვა თავისით Cloudflare საიტს არ აახლებს. ახალი ვერსიის გასაშვებად პროექტის საქაღალდიდან გაუშვი:

```bash
npm run deploy
```

არ შეცვალო `wrangler.jsonc`-ში Worker-ის სახელი ან Durable Object-ის კონფიგურაცია, რათა ძველი ონლაინ ჯავშნები შენარჩუნდეს.

## შემოწმება

```bash
npm run check
npm run test:integration
```

ინტეგრაციული ტესტები დროებით Wrangler სერვერსა და იზოლირებულ საცავს იყენებს.
